# Вдвоём

Личное веб-приложение для пары: хотелки, покупки, сравнение цен по магазинам, дела, фильмы и сериалы.

## Возможности

- общий список на двух телефонах с синхронизацией;
- вход по одному коду пары;
- фотографии хотелок в объектном хранилище;
- сравнение фасовок по цене за единицу и реальной стоимости целых упаковок;
- отдельные удобные карточки сравнения цен на телефонах;
- прогресс сериалов по сезону и сериям;
- постраничная отрисовка длинных списков и автоматический повтор синхронизации;
- установка на экран «Домой» как веб-приложения;
- защита от перезаписи более свежих изменений со второго устройства.

## Структура интерфейса

- `public/app.html` — основа страницы;
- `public/app.css` — оформление и адаптация;
- `public/app.js` — интерфейс и работа с данными;
- `public/price-engine.js` — отдельный расчёт выгодных покупок.

## Локальная проверка

```text
pnpm install
pnpm run lint
pnpm run typecheck
pnpm run verify
pnpm run build
```

Для сервера нужна секретная переменная `COUPLE_CODE_HASH` с SHA-256 хэшем общего кода, а также D1-привязка `DB` и R2-привязка `FILES`.
