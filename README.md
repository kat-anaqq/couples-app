# Вдвоём

Личное веб-приложение для пары: хотелки, покупки, сравнение цен по магазинам, дела, фильмы и сериалы.

## Возможности

- общий список на двух телефонах с синхронизацией;
- вход по одному коду пары;
- фотографии хотелок в объектном хранилище;
- подбор магазина с минимальной ценой для каждого продукта;
- установка на экран «Домой» как веб-приложения;
- защита от перезаписи более свежих изменений со второго устройства.

## Локальная проверка

```text
pnpm install
pnpm typecheck
pnpm build
```

Для сервера нужна секретная переменная `COUPLE_CODE_HASH` с SHA-256 хэшем общего кода, а также D1-привязка `DB` и R2-привязка `FILES`.
